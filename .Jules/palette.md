## 2023-10-27 - [Accessible Structural Cards]
**Learning:** In React applications where structural components (like a div acting as a card) are heavily used for primary navigation and selection (such as `PlayCard` used in search results), simply attaching an `onClick` handler ignores keyboard and screen-reader users entirely. Interactive non-semantic elements must have keyboard listeners (`onKeyDown` for Enter/Space), an appropriate ARIA role (`role="button"`), a `tabIndex`, and, importantly, visible focus rings to orient keyboard navigators.
**Action:** When inspecting search result structures or lists composed of custom divs/cards in the future, check if they are the primary interaction point. If they are, upgrade them to be fully functional buttons or wrap them in semantic elements rather than only depending on pointer events.
